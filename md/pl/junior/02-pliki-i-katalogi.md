# 02. Pliki i katalogi

Prawie wszystko na komputerze jest zapisane jako **plik**. Katalog, nazywany też folderem, służy do porządkowania plików i innych katalogów.

## Nazwa i rozszerzenie

Plik może nazywać się:

`kot.jpg`

Tutaj:

- `kot` jest nazwą,
- `.jpg` jest rozszerzeniem.

Rozszerzenie często podpowiada, co znajduje się w pliku.

| Rozszerzenie | Zwykle oznacza |
|---|---|
| `.jpg`, `.png` | obraz |
| `.txt` | zwykły tekst |
| `.md` | tekst Markdown |
| `.html` | stronę WWW |
| `.css` | wygląd strony |
| `.js` | program JavaScript |

## Ścieżka

Ścieżka mówi, gdzie znajduje się plik.

Na przykład:

`projekty/moja-strona/index.html`

oznacza plik `index.html` w katalogu `moja-strona`, który znajduje się w katalogu `projekty`.

## Zrób własne laboratorium

Utwórz katalog:

`tech-lab`

W nim utwórz katalog:

`moja-strona`

A w środku pusty plik:

`index.html`

Będziemy go używać w następnych rozdziałach.

## Ważna zasada

Nie zmieniaj i nie usuwaj plików systemowych tylko dlatego, że ktoś w internecie napisał, że „można”. Najpierw sprawdź, do czego służą.

## Zapamiętaj

Pliki przechowują dane. Katalogi robią porządek. Ścieżka jest adresem pliku na komputerze.
